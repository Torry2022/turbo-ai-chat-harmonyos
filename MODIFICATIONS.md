# Modifications

Turbo AI Chat is derived from
[`Turbo1123/turbo-ai-chat-harmonyos`](https://github.com/Turbo1123/turbo-ai-chat-harmonyos).
The retained upstream baseline is commit
[`f946a842`](https://github.com/Turbo1123/turbo-ai-chat-harmonyos/commit/f946a842c371fd2d00e0e33369ae8efc7b564474).
The first two commits, `37956e7` and `f946a842`, form the upstream history;
development from the third commit, `12da6ad`, onward belongs to this repository's
subsequent work.

Implementation files inherited from that baseline and subsequently changed
carry a short modification notice. This is limited to files that contain the
upstream project's own implementation; project scaffolding, generated metadata,
artwork, and third-party MNN files are not labelled as upstream-authored code.
Newly added files do not use that notice.

The complete history and code difference are available in Git and in the
[`f946a84...main`](https://github.com/Torry2022/turbo-ai-chat-harmonyos/compare/f946a842...main)
comparison. Third-party MNN binaries and headers remain covered by the MNN
license information recorded in `NOTICE` and the repository documentation.

The main implementation changes are documented in
[`docs/architecture/core-inference-evolution.md`](docs/architecture/core-inference-evolution.md).
